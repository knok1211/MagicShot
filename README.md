# MagicShot (매직 샷)

## 📖 게임 소개
**MagicShot**은 플레이어가 마법 발사체를 발사하여 적을 처치하는 **탑다운 퍼즐 슈팅 디펜스 게임**입니다. 
플레이어는 스테이지 시작 전, 제한된 '코스트(Cost)' 내에서 맵 상에 다양한 속성을 가진 특수 블록들을 배치하여 발사체의 반사 경로를 설계하고, 다가오는 적들을 효율적으로 처치해야 합니다.

## 🎮 주요 특징

### 1. 발사체 반사 시스템 (Projectile Reflection)
* 플레이어가 쏘는 마법 발사체는 벽이나 설치된 특수 블록에 닿으면 튕겨 반사됩니다.
* 반사 각도를 계산하여 맵의 여러 적들을 한 번에 타격하는 당구 형태의 전략적인 플레이가 요구됩니다.
* 발사체가 지나간 궤적은 적들에게 위험 지대(Danger Zone)로 인식되어 적들의 이동 경로에 영향을 줍니다.

### 2. 전략적 블록 설치 (Cost 시스템)
* 각 스테이지가 시작되기 전, 플레이어는 정해진 최대 Cost 내에서 블록을 자유롭게 그리드 맵에 설치하거나 삭제할 수 있습니다.
* 설치한 특수 블록에 발사체가 반사될 경우, 해당 블록의 마법 속성이 발사체에 부여되어 강력한 추가 효과가 발생합니다.

#### 🧱 블록 종류 및 효과
| 블록 이름 | Cost | 설명 및 효과 |
| :--- | :---: | :--- |
| **일반 블록 (Normal)** | 1 | 일반적인 벽의 역할을 하며, 발사체를 특수 효과 없이 반사시킵니다. |
| **얼음 블록 (Ice)** | 2 | 반사된 발사체가 얼음 속성을 띱니다. 피격된 적은 3초 동안 이동 속도가 50% 감소합니다. |
| **화염 블록 (Fire)** | 3 | 발사체가 화염 속성을 띠며, 반사되는 순간 여러 개의 발사체로 분열합니다. |
| **독 블록 (Poison)** | 3 | 발사체가 독 속성을 띱니다. 피격된 적에게 최대 체력의 10%에 해당하는 추가 고정 데미지를 입힙니다. |

### 3. 적 지능적 이동 AI (Dijkstra Algorithm)
* 적들은 블록이 막혀있는 공간과 발사체 위험 지대를 피하며 가장 최적의 경로로 플레이어를 향해 접근합니다. (다익스트라 알고리즘 사용)
* 플레이어가 전략적으로 블록을 배치하여 적의 동선을 길게 우회하도록 유도할 수 있습니다.

## 🛠️ 시스템 조작 방법
* **이동**: `W`, `A`, `S`, `D` 또는 `방향키`
* **조준**: 마우스 커서 방향
* **발사**: 마우스 좌클릭 (일정 쿨타임 존재)
* **스테이지 준비**: 화면의 UI 버튼을 눌러 블록을 선택 후 마우스로 좌표를 지정하여 설치/삭제. 준비가 끝나면 완료 버튼 클릭 시 적들이 스폰되며 전투 시작.
